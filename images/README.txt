- 権利者から削除の要望があった場合は、data/profile.js と data/slides.js の image を "" にすれば表示が消えます。

画像を追加・差し替えるとき
1. 元画像を「画像」フォルダに保存する
2. 長辺 1200px 程度・JPEG 品質 80 に縮小してこのフォルダに保存する（Claude Code に「縮小して images に置いて」と伝えてもよい）
3. data/slides.js や data/profile.js の image にファイル名を書く
